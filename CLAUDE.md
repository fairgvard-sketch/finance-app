# Домашний хаб — CLAUDE.md

## Обзор проекта

Мобильное веб-приложение — **домашний хаб для пары** (мобайл-фёрст). Развилось из финансового трекера. SPA на чистом HTML/CSS/JS без фреймворков, деплоится на Firebase Hosting, данные в Firebase Realtime Database.

Два «мира», переключаемых сверху:
- 💰 **Деньги** — доходы, расходы, копилка, бюджеты, автоплатежи (личные, `users/{uid}`)
- 🏠 **Дом** — запасы/холодильник, дела (дежурства+задачи), рецепты (общие для пары, `household/{id}`)

**Рабочий файл — `public/index.html`** (НЕ корневой `index.html`, тот устарел). Firebase деплоит папку `public/`.

**Firebase проект:** `financial-app-9c4fa`
**Деплой:** `firebase deploy --only hosting`
**Локально:** открыть `public/index.html` через веб-сервер (не `file://` — Firebase SDK требует http)

## Архитектура

**Стратегия — «обернуть, не переписывать»**: рабочий финансовый монолит (весь `<style>`+`<script>` в `public/index.html`, ядро — функция `render()` по табам) сохранён как **мир «Деньги»**. Вокруг построена модульная оболочка домашнего хаба.

> ⚠️ **«Деньги» — НЕ заморожены.** Мир «Деньги» активно редизайним наравне с «Домом»: оба мира приведены к **единой дизайн-системе** (тёплая кремовая палитра, токены `theme.css`, шрифты Unbounded + Manrope, duotone/контурные SVG-иконки вместо эмодзи и голых символов). Логику финансов (`render()`, сохранение, авто-списания) не ломаем, но визуал — карточки, цвета, иконки, стрелки, шрифты — менять можно и нужно. Не считай легаси-`<style>` или инлайн-стили «неприкосновенными».

```

  js/
```

### Контракт home-модулей
Каждый раздел мира «Дом» регистрируется так:
```js
window.HomeModules.register("stock", {
  render(mainEl) { mainEl.innerHTML = "..."; },  // рисует раздел в #main
  onAdd() { /* реакция на контекстную кнопку [+] */ }
});
```
- Оболочка вызывает `render()` при входе в раздел и `onAdd()` при тапе `[+]`.
- Общие данные читать из `window.Household.data.{stock|tasks|recipes}`, сохранять через `window.saveHousehold(section, value)`.
- `window.toast(msg)` — лёгкое уведомление.
- Иконки нав-панели: `<symbol id="ico-…">` в `index.html` (grid/box/check/chef уже добавлены).

### ⚠️ ПРАВИЛО ИКОНОК: всегда SVG, НЕ эмодзи и НЕ голые символы

Правило действует **в обоих мирах** — и в «Доме», и в «Деньгах».

**1. Содержательные иконки сущностей — Phosphor duotone.** Фигура рисуется дважды (бледная заливка `opacity .2` + контур `stroke` поверх), один цвет на иконку, в плашке с фоном `color + '1a'` (~10%). Так сделаны категории финансов (`CATEGORY_META`, `catIcon`/`catTile` в `index.html`) и места хранения / разделы «Дома».
- `window.duoIcon(key, size)` → `<svg>` duotone-иконка
- `window.duoTile(key, size, tileSize)` → иконка в цветной плашке
- `window.HOME_ICONS` / `window.HOME_ICON_COLOR` — реестр; новые иконки добавляй сюда (svg с плейсхолдерами `stroke="C"`/`fill="C"`, плюс цвет).

**2. Управляющие глифы — контурные SVG (один штрих, без заливки).** Стрелки, плюс/минус, крестик, галочка, часы, шеврон и т.п. — НЕ символы `←`/`+`/`×`/`✓`/`›`.
- `window.uiIcon(key, size, color?)` → контурный глиф (`arrow-left, chevron, plus, minus, close, check, clock, warn, serving, search, heart/heart-fill, rotate, clipboard, leaf`); по умолчанию `currentColor`.
- `window.UI_GLYPHS` — реестр глифов; новые добавляй сюда тем же штрихом (1.6–2px).
- В легаси-`index.html` для тех же целей используется SVG-спрайт `<symbol id="ico-…">` (`ico-arrow-left`, `ico-close`, `ico-plus`, `ico-chevron-right`, `ico-check` …) через `<use href="#ico-…"/>`.

**Нельзя** ставить голые эмодзи (🍽️, 🗑️, ❤️, 🛒) как основные иконки и голые символы (`←`, `+`, `×`, `✓`, `⚠`, `⏱`) как кнопки/бейджи — это «удешевляет» вид и ломает консистентность. Эмодзи допустимы только как **мелкий декор в тексте** (например, 🌿 в приветствии). Знаки `+`/`−` перед суммой — это **типографика чисел**, их оставляем текстом. Нужной иконки нет в реестре — добавь её туда (duotone или контур), а не подставляй эмодзи/символ.

### Интеграция со старым кодом
Легаси `go()`, `render()`, `_fbInit()` сделаны shell-aware: переключают/уважают активный мир. Когда `Shell.world==="home"`, финансовый `render()` делегирует в `renderHome()`. CSS оболочки переопределяет легаси через `body[data-world]` для нужной специфичности (легаси `<style>` грузится позже).

**Разделы файла:**
- `<style>` — все легаси-стили мира «Деньги». Приведены к тёплой палитре (`theme.css`): кремовые поверхности `#fffdf9`, фон `#f4f1ea`, тёплый серый текст, шрифты Unbounded+Manrope. Акцент бренда «Деньги» — зелёный `#1a4a35`. CSS-переменные в этом блоке пока не используются (значения захардкожены), но цвета держим **согласованными с токенами** `theme.css`.
- Firebase SDK — подключается через CDN (compat версия 9.23.0)
- Блок аутентификации — Google Sign-In через popup
- Константы и данные (`ECATS`, `ICATS`, `SVCS`, `COLORS`, `ICONS`)
- Логика — функции `render()`, `go()`, `openSheet()` / `closeSheet()` и т.д.
- HTML оверлеи (bottom sheets) для каждой формы

## Структура данных Firebase

**Личные финансы** — `users/{uid}/`:
```
txs        — массив транзакций [{id, type, amount, cat, note, date}]
subs       — массив подписок [{id, n, amt, day, autoCharge}]
goals      — массив целей копилки [{id, name, target, saved, icon, color, deadline}]
budgets    — объект бюджетов {cat: amount}
recurrings — автоплатежи [{id, type, amount, cat, note, freq, day, subId}]
householdId — ссылка на общее пространство пары
```
Сохранение: `saveAll()` → `window.saveToFirebase()`.

**Общий быт пары** — `household/{householdId}/`:
```
members  — {uid: {name, photo, email}}
stock    — Этап 2 (запасы)
chores/tasks — дежурства (очередь) + разовые задачи
recipes  — Этап 4 (рецепты)
```
Bootstrap в `household.js` (`initHousehold`): при первом входе создаётся household, id пишется в `users/{uid}/householdId`. Подписка `.on("value")` держит `window.Household.data` живым. Сохранение: `window.saveHousehold(section, value)`.

## Дизайн-система (единая для обоих миров)

- **Палитра** — тёплая «бумажная»: фон `#f4f1ea`, поверхности `#fffdf9`, текст `#221f1a`/тёплый серый. Токены в `theme.css`. Акценты миров: «Деньги» — зелёный `#1a4a35`, «Дом» — тёплая охра/янтарь `#bd7d1f`.
- **Шрифты** — `Unbounded` (заголовки и крупные числа, `.font-display`) + `Manrope` (текст/UI). `Outfit` больше не используется. Грузятся одним `<link>` в `index.html`.
- **Иконки** — только SVG: duotone для сущностей (`duoIcon`/`duoTile`/спрайт `#ico-…`), контурные глифы для управления (`uiIcon`/спрайт). Никаких эмодзи/символов как иконок (см. «ПРАВИЛО ИКОНОК»).
- **Геометрия/тени** — из токенов (`--r-*`, `--sh-*`); карточки скруглённые, тени мягкие тёплые.
- Меняя UI в одном мире, держи второй визуально согласованным.

## Правила при изменениях

- Все правки финансов вносятся в `public/index.html`; разделы «Дома» — в `js/home/*` и `css/*`
- Не добавлять отдельные JS/CSS файлы без явной необходимости
- Язык интерфейса — **русский**
- **Оба мира редизайним** — «Деньги» не заморожены; визуал свободно меняем, логику финансов не ломаем
- Новый UI — строго по «Дизайн-системе» выше (палитра, шрифты, SVG-иконки)
- Анимации через CSS transitions/keyframes, не JS-библиотеки
- После изменений деплоить: `firebase deploy --only hosting` (локально доступен через `npx firebase …`)
